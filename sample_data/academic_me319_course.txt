=== Course Content ===
1. Introduction to Control Systems
   - Basic concepts, feedback control
   - System modeling approaches
   
2. Mathematical Modeling
   - Transfer functions
   - Block diagrams
   - State-space representation
   
3. Time and Frequency Response Analysis
   - Laplace and Fourier transforms
   - First and second order systems
   - Stability analysis (Routh-Hurwitz criterion)
   
4. Controller Design
   - PID controller design for DC Motor
   - Tuning methods (Ziegler-Nichols)
   
5. Digital Implementation
   - Arduino as digital controller
   - Discrete-time systems
