Fieldnote

Your notes stay on this machine. Ask a question, and the answer comes back with the passage it used.

OllamaChromaStreamlit
  1. 01 · File itA PDF, a text file, or a typed note goes into one of six folders.
  2. 02 · Embed itnomic-embed-text, running in Ollama, stores the chunks in a local Chroma index.
  3. 03 · AskThe question is rewritten for search, then limited to the folders and dates you picked.
  4. 04 · Go furtherOn the retrieved text: a pattern, an insight, a chart, or a pass over a whole folder.

Question

  • Can a private archive answer from the notes you choose, and show where the sentence came from?

Why this path

  • A single prompt over every note mixes a bill with a journal. Folders and dates are the filter.
  • Local models keep the archive off a hosted API. llama3 writes. The embedder never leaves the machine.

What held

6folders: Academic, Journal, Bills, Events, Personal, Ideas
44chunks already in the store
7documents behind those chunks

Reading the result

  • A question over Academic returns the course notes that were retrieved, and says when the notes do not contain the thing you asked.
  • Pattern and insight run on that same context. If the text has numbers, the insight step can chart them.
  • A separate pass summarizes whole folders across a date range, instead of answering one question.

A real output

folders Academic query academic notes chunks cited from the course file writer llama3, local

Sample notes live in sample_data.

What is switched on

  • The running writer is llama3. Embeddings are nomic-embed-text.
  • A fine-tuned adapter is kept under fine_tuning and left off, so the app uses the models already pulled.

Needs. Ollama has to be up, with those two models pulled. If it is down, the page has nothing to answer with.

Stack

Streamlit, Chroma, Ollama. Environment is IBU_venv.
