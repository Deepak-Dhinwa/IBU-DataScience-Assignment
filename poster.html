Personal Memory Agent

Notes stay on this machine. A small set of local agents answers from the notes you choose, not from the open web.

OllamaChromaStreamlit

Question

  • Can a personal archive answer a question and show where the answer came from?
  • The assignment asked for agents over a private store, with no hosted LLM.

Method

  • PDFs, text, and typed notes go into six folders in a local Chroma store.
  • llama3 writes. nomic-embed-text embeds. Both run in Ollama.
  • A pattern miner and an insight writer run on the retrieved passages.

Evidence

What the result actually says

  • A note, a PDF, or a text file lands in one of six folders: Academic, Journal, Bills, Events, Personal, Ideas.
  • Answers are restricted to the folders and the date range you pick, and they come back with the passages that were retrieved.
  • The store already has 44 chunks from 7 documents. Sample notes are in sample_data.

What it does not show

  • Nothing here calls an external LLM. If Ollama is down, or llama3 and nomic-embed-text are not pulled, the page has nothing to answer with.
  • The fine-tuned adapters under fine_tuning are kept and switched off. USE_CUSTOM_FINETUNED_MODEL is false, so the running app is llama3.

Beside the other attempts

  • Pattern miner and insight writer run on the retrieved text. If the text has numbers, the insight writer can chart them.
  • A separate global pass summarizes whole folders over a date range, instead of answering one question.

Stack

Streamlit, Chroma, Ollama. Generation is llama3. Embeddings are nomic-embed-text. Environment is IBU_venv.
